# URL Shortener

![CI](https://github.com/gustav0-001/url-shortener/actions/workflows/ci.yml/badge.svg)

Сервис сокращения ссылок с одностраничным сайтом, счётчиком переходов и сроком жизни ссылок.

**Демо:** https://shortlink-url-fzmk.onrender.com  
**Swagger:** https://shortlink-url-fzmk.onrender.com/docs

> Демо работает на бесплатном тарифе: после простоя первое открытие может занять около минуты, пока сервис «просыпается».

## Возможности

- Создание короткой ссылки (`POST /links`) с необязательным сроком жизни `expires_in_days` (1–365 дней)
- Редирект 302 со счётчиком переходов; по истечении срока ссылка отвечает 410
- Страница сайта: форма, копирование в буфер, список «Мои ссылки» (хранится в браузере)
- Ограничение частоты создания ссылок (по умолчанию 10 в минуту с одного IP)
- Список всех ссылок и удаление закрыты токеном администратора
- Миграции схемы через Alembic, применяются автоматически при старте контейнера
- CI на GitHub Actions (тесты и сборка Docker-образа), автодеплой на Render

## Стек

FastAPI, SQLModel (SQLAlchemy), PostgreSQL, Alembic, Docker, pytest, GitHub Actions.
Деплой: Render (приложение) и Neon (PostgreSQL).

## Архитектура

```
Браузер ──► FastAPI (Render, Docker) ──► PostgreSQL (Neon)

app/routers      HTTP-слой: эндпоинты, коды ответов
app/services     логика: генерация кода, клики, срок жизни
app/ratelimit.py ограничение частоты создания ссылок
app/security.py  токен администратора
app/static       страница сайта (HTML, CSS, JS без фреймворков)
migrations/      миграции Alembic
```

## API

| Метод и путь | Описание | Доступ |
|---|---|---|
| `POST /links` | Создать ссылку: `{"original_url": "...", "expires_in_days": 7}` | публично, с лимитом частоты |
| `GET /{short_code}` | Редирект (302); 404 если ссылки нет, 410 если срок истёк | публично |
| `GET /links/{short_code}` | Статистика ссылки (клики, срок жизни) | публично |
| `GET /links` | Все ссылки, пагинация `limit` и `offset` | токен администратора |
| `DELETE /links/{short_code}` | Удалить ссылку | токен администратора |
| `GET /health` | Проверка живости сервиса | публично |

Админ-эндпоинты ждут заголовок `Authorization: Bearer <ADMIN_TOKEN>`.

Пример:

```
curl -X POST https://shortlink-url-fzmk.onrender.com/links \
  -H "Content-Type: application/json" \
  -d '{"original_url": "https://example.com/very/long/path", "expires_in_days": 7}'
```

## Запуск локально

Приложение вместе с базой одной командой:

```
docker compose up --build
```

Сайт: http://localhost:8000  
Swagger: http://localhost:8000/docs

Разработка без контейнера для приложения (скопируй `.env.example` в `.env`):

```
docker compose up -d db
alembic upgrade head
uvicorn app.main:app --reload
```

## Тесты

```
pip install -r requirements-dev.txt
python -m pytest -v
```

Тесты идут на встроенной SQLite в памяти, поэтому не требуют базы. В CI дополнительно считается покрытие.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `BASE_URL` | `http://localhost:8000` | адрес сервиса, из него строится `short_url` |
| `DATABASE_URL` | `sqlite:///links.db` | строка подключения к базе |
| `ADMIN_TOKEN` | пусто | токен администратора; если не задан, админ-эндпоинты закрыты для всех |
| `CREATE_RATE_LIMIT` | `10` | число созданий ссылок за окно с одного IP (`0` отключает лимит) |
| `CREATE_RATE_WINDOW` | `60` | размер окна в секундах |
| `LOG_LEVEL` | `INFO` | уровень логирования |

## Принятые решения

- **Редирект 302, а не 301.** Браузеры кэшируют 301 навсегда, и повторные переходы не доходили бы до сервера, а счётчик кликов переставал бы расти.
- **Уникальность кода обеспечивает база.** Вместо проверки перед вставкой используется unique-ограничение и повтор при `IntegrityError`: так нет гонки при параллельных запросах.
- **Счётчик кликов атомарный:** `UPDATE ... SET clicks = clicks + 1`, а не чтение и запись из приложения.
- **Лимит частоты в памяти процесса.** Реальный IP берётся из `True-Client-IP` (Render за Cloudflare), потому что `X-Forwarded-For` клиент может подделать.
- **Токен администратора** сравнивается через `secrets.compare_digest`; без заданного токена админ-эндпоинты недоступны.
- **`pool_pre_ping`** включён, потому что бесплатный Neon усыпляет базу после простоя и соединения в пуле «умирают».
- **Валидация адреса:** только `http` и `https`, ограничение длины, ссылки на собственный домен отклоняются (чтобы не получались циклы редиректов).
- **Миграции применяются при старте контейнера**, что просто и достаточно для одного экземпляра.

## Ограничения

- Бесплатный тариф: «холодный старт» до минуты после простоя.
- Лимит частоты хранится в памяти процесса: сбрасывается при перезапуске и не общий между несколькими экземплярами.
- Тесты идут на SQLite, а не на PostgreSQL.
- Нет учётных записей пользователей: ссылки привязаны к браузеру через `localStorage`.

## Что можно улучшить

Учётные записи и привязка ссылок к владельцу, подробная статистика переходов, собственный короткий домен.
